# Tong-PPT-design-Tong 
Tong 维护的 AI 演示文稿设计技能，适配 Codex、Claude Code 等 Agent。内置杂志风、瑞士风、摄影作品集等六套视觉风格，支持生成横向翻页 HTML 演示，提供 PPTX/CDR 模板及配图工作流，适用于演讲分享、个人介绍、设计作品集、品牌汇报与空间设计提案。
